# 《如鸢》自动剧情脚本配置

本脚本由雷电模拟器中控的辅助端运行。

## 当前策略

- 普通对话：识别到剧情对话指示模板后自动推进。
- 剧情选项：只执行 `option_routes` 中明确配置的路线，不随机、不默认点第一个。
- 路线缺失或指定选项未出现：停止该模拟器并记录日志。
- 长时间无法识别画面：安全暂停，并保存诊断截图。

## 配置文件

配置文件：`scripts/ruyuan/config.json`

### 固定攻略路线格式

`option_routes` 每一项包含：

- `when`：当前剧情节点的完整文本，必须能被 Android UI 层级读取。
- `choose`：攻略要求选择的完整选项文本。

例如（仅为格式示例，不代表游戏真实剧情）：

```json
"option_routes": [
  {
    "when": "示例剧情节点甲",
    "choose": "示例选项乙"
  },
  {
    "when": "示例剧情节点丙",
    "choose": "示例选项丁"
  }
]
```

请把示例文字替换成你实际采用的攻略文本。没有匹配路线时脚本不会猜选项。

## 画面模板

把 PNG 模板放入 `scripts/ruyuan/templates/`，并在 config.json 的 `templates` 中配置相对路径：

- `start_game.png`：开始/进入游戏按钮
- `continue.png`：确认或继续按钮
- `map_forward.png`：地图前进/下一节点按钮
- `dialogue_next.png`：剧情推进按钮
- `dialogue_indicator.png`：确认当前处于可自动推进的剧情对话画面

模板应从当前游戏版本、当前模拟器分辨率的清晰截图中裁切，尽量只保留按钮或稳定图标，不要包含变化中的文字、动画或背景。匹配阈值需要实机验证。

## 重要限制

1. 当前版本提供了辅助端启动/停止入口和脚本执行线程，但尚未完成《如鸢》实机画面标定。
2. 游戏若使用纯 Canvas 绘制，Android UI 层级可能拿不到剧情文本；这种情况下需要 OCR 或选项区域的图像模板/图色识别扩展，不能假设文字路线已经可用。
3. 当前没有附带真实游戏按钮模板，也没有预置未经验证的剧情攻略。配置为空时不会自动推进未识别的画面。
4. 诊断截图默认保存在 Windows 临时目录下的 `zk_ruyuan/diagnostics` 文件夹中。
5. 首次建议只选一台模拟器验证，不要直接批量运行。
