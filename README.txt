雷电模拟器局域网中控 V2.0（基础框架版）
========================================

本版本范围
- 同一套软件，启动时选择主控模式或辅助模式。
- 主控端 TCP 监听；辅助端主动连接；心跳与设备注册。
- 主控端账号五分类管理：待用、在线、完成、异常、其他。
- 异常账号可记录异常类型和原因。
- 主控端辅助端列表、连接状态、日志基础界面。
- 任务管理、脚本管理、图色识别、图片匹配、OCR 页面和接口位置已预留。
- 暂不包含任何具体游戏脚本或游戏内自动操作流程。

运行环境
1. Windows 10/11，建议 Python 3.10 或更新版本。
2. 安装依赖：python -m pip install -r requirements.txt
3. 启动：python main.py

局域网连接
1. 主控电脑启动软件，选择“主控模式”，设置监听端口（默认 8765）。
2. 在 Windows 防火墙中允许本程序在专用网络通信。
3. 辅助电脑启动同一软件，选择“辅助模式”，填写主控电脑局域网 IPv4、端口、设备名称和连接密钥。
4. 两端配置的连接密钥必须一致。请修改 config.json 中默认示例密钥，不要继续使用占位值。
5. 建议仅在可信局域网使用，不要将监听端口映射到公网。

重要说明
- 当前仅实现连接握手阶段的共享密钥身份验证；尚未启用 TLS 传输加密，也未对后续每条消息做签名。请只在可信局域网测试，不要将账号密码或其他敏感数据通过此版本网络传输。
- 当前账号密码字段在数据库中不保存明文密码；本版本先不实现远程账号密码分发。
- 辅助端断线不会自动把账号改为异常；需由主控端确认后处理。
- 当前“任务管理”和“脚本管理”是预留框架，不执行游戏操作。
- 图像识别模块提供本地截图、颜色检测、模板匹配基础接口；OCR 仅预留接口。
- 本版本是新架构基础版，不会自动覆盖或迁移旧 V1.6.1 的 config.json/数据库。首次运行前请备份旧项目。
